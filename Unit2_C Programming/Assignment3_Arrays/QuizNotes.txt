-if a[3] is an array, 3 is the number of elements it can handle including '\0'
meaning if you were to initialize a[3] = "abc" for example and print it later, you'd end up
with garbage value in the print because the array doesn't see '\0' in the string.
here: a[0] = 'a',   a[1] = 'b'  ,a[2] = 'c' 
**NOTE THERE'S NO a[3]!!! because 3 is just the amount of elements you choose to have.
so if you wanted to store 3 values in an array you have to make it a[n+1] so that would mean a[4].
which would make it so that a[3] = '\0' and end the printing process resulting in normal outcome.

strcpy(x,y): copies string y onto x
strcat(x,y): adds string y to the end of string x
strcmp(x,y): compares string x with y and returns 0 if identical and 1 if not.
NOTE you cannot compare 2 strings using == operator because you'd be passing the
addresses of strings when you do that. you can either compare one specific location
of a string or use strcmp(x,y) to compare the whole string.

-If we were to say str1[20] is a string of integers at an address of 0x0.
then we wanted to print &str1+1.
that would not print element str1[1] as we would expect, instead it would take
the value of the string's base address (0x0) and add to it 1 instance of the size of the whole
array's address, i.e 4*20 = 80.
so the console would print &str1+1 = 0x80
IF we wanted to just print the address of an element in an array we just have to type it as
printf("%p",str1+1); or printf("%p",&str1[1]);
