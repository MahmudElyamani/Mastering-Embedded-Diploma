7. //C code to check if a number is repeated in an array or not
uint32_t isRepeated(uint32_t arr[], uint32_t arraySize, uint32_t Num) {
    uint32_t count = 0;
    for (uint32_t i = 0; i < arraySize; i++) {
        if (arr[i] == Num)
            count++;
    }
    return count;
}



8. //Difference between NULL, Dangling and void pointers
Null pointers are initialized to point at 0.
Dangling pointers are pointers which point to a variable that's no longer visible within the current scope they're called from.
void pointers are pointers that do not have a type during initialization but require type casting when dereferenced or called.




9. //Difference between macros and functions
Macros are code snippets which are assigned a symbol used within the code, during pre-processing time these symbols are replaced 
by the code snippets they were assigned and the code is expanded.
Functions are a sequence of operations that are called within the main program bracket, once called the program counter points to the
first instrucion of the function to start executing it, they do not replace already existing lines that reference them.
