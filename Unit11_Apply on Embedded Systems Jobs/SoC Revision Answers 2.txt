1. //How to decide whether a given MCU is using little endian format or big endian?
- This depends on how the MCU handles bits, if it reads bits from the MSB side then its formatting is big endian, otherwise it's little endian

2. //Difference between RISC and CISC Processors
In CISC complexity is found in hardware, Less lines of code needed to provide same functionality instructions have different sizes
and are harder to decode.
In RISC complexity is on the software side, requires more instructions to provide same functionality, all instructions have the same size
and easier to decode.
