1. //What is interrupt latency?
The maximum amount of time an interrupt is delayed before the CPU starts executing the 1st instruction in the ISR

2. //How can you optimize interrupt latency?
Decreasing the amount of instructions within a function that the CPU has to go through.

3. //What is ISR?
A sequence of operations that's executed by the ECU when an interrupt is invoked corresponding to the ISR number.

4. //What is return type of ISR
ISR returns void, when the CPU encounters a return statement in an ISR it loads the stored address from stack to the program counter.

5. //Can we use any function inside ISR

9. //What happens when an interrupt occurs in detail
• When an interrupt occurs, the CPU finishes executing the current instruction its at.
• It then stores the address of the next instruction in the stack and points the program counter to the start of the ISR.
• It then sends an acknowledge signal to the interrupt controller to clear the interrupt bit.
• then starts executing the interrupt service routine (ISR)
• once it encounters a return statement it loads back the stored address from the stack to the program counter and continues the program.
