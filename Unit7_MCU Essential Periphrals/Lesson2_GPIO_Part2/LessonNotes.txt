This Lesson tackles the alternative functions in GPIO pins
a GPIO pin can be programmed through the pin's MUX to have a different function depending on the TRM

List all the alternative connection with Port A pin 7 in TivaC:
• According to table 10-2 page 650 in TivaC's TRM pin 7 port A can be an I2CSDA pin or PWM3 pin

-Sometimes the TRM of an SOC has a specific register that lets you choose which alternative function the pin operates at based on
the binary you write on the register like in the case of TivaC.
However sometimes it can also be mentioned all together without registers like in STM32 where it says possible alternate functions
for the pin as I2CSD/UARTRX/CANTX. If that is the case then to choose which one you want to operate at you have to enable them
through their own register or by enabling their clock in the clock enable register.

Explain remapping in a MCU:
• Some peripherals within a microcontroller could be or could not be present on the MCU depending on its packaging type. for example
  in the STM32F103C6 the periphral TIM4_ETR is tied to PE0 which is non-existant in the packaging VFQFPN36 but exists in
  packaging types like LFBGA100.
• IN ORDER TO USE THESE PERIPHERALS there's a functionality that's been invented called "function remapping" as it is possible to
  remap some alternate functions to other pins.
• These remap options exist in the alternate function section in the TRM.
• Remapping is also useful for when wanting to use 2 or more alternate functions at once, for example if we want to use both the
  SPI2_SCK and TIM1_BKIN functions that are tied to pin PB13 we can enable SPI2_SCK on that pin and remap pin PD7 to operate as 
  the TIM1_BKIN pin since it has that as a remap option.
• You can change the functionality to it's mapped version by writing to the map registers found in the TRM, there could be 1 or more.

What's the event function in alternative functions used for?:
• the event register is a cortex arm based register that sends a pulse through the pin based on the CPU's activity.
• The pin could be determined through the register pin number and port number configuration and enabled after.
• when multiple MCU's are present on an ECU it is necessary to perserve power so to do that we put some MCU's to sleep.
• If lets say for example an MCU is responsible for reading data and the other is responsible for sending information we can
  put the CPU of the one that sends information to sleep until it gets an event signal from the other CPU that recieves information
  so that it only operates truely once data has been gathered.
• in this mode the MCU does not respond to any other actions the user takes, not even interrupts as they require the CPU to be awake and operating.
• However when recieving this event pulse it must be through an external interrupt register after enabling its event mask register.

What is a MCU device header and what does it include?:
• When writing a driver for an MCU you have to make a header file with the MCU's name such as STM32F103C6.h which is called device header
  this header file has all the adresses, offsets and information regarding that MCU.
• it also contains other important stuff like base address for each module in the MCU
• clock management macros
• IRQ definitions
• Peripheral registers definition structure
