Elaborate the difference between port-mapped I/O and memory mapped I/O:
• Port mapped I/O requires special instructions, the memory address space and the I/O device address space are independent of
  each other, for example, Intel x86 processors use IN and OUT instructions to read or write to a port.
• Memory mapped I/O is what we use in embedded systems, doesn't require special instructions, The memory and I/O devices share
  the same address.

-If a system bus is 32 bit, that means the CPU can issue transaction to 2^32 of different address (4GB)

What's the difference between Bit, Byte, Halfword, Word, Double-word and Nibbles?:
• A nibble is a group of 4 bits.
• 1 byte is 8 bits
• Halfword is 2 bytes or 16 bits
• a Word has 4 bytes or 32 bits.
• a double word has 8 bytes or 64 bits

What's the difference between Little Endian and Big Endian?:
• In little endian the low-order byte is stored in the lowest address and the high order byte in the highest address (from bottom up).
• In Big endian the low-order byte is stored in the highest address and the high-order byte in the lowest address (from top to bottom).
